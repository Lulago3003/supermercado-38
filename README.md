# Supermercado 38

Sitio web comercial de varias páginas para Supermercado 38, Arraiján, Panamá Oeste.

## Páginas

- Inicio
- Ofertas de la semana
- Pedido rápido
- Departamentos
- Panadería
- Cotiza por WhatsApp
- Contacto y ubicación

Es un sitio estático: puede visualizarse abriendo `index.html` en cualquier navegador o publicarse directamente desde GitHub Pages.

## Imágenes

- Las páginas usan las fotos de `img/` en formato **WebP**, que pesan menos de la mitad que los JPG. Los `.jpg` de `img/` se conservan como respaldo; `img/fachada.jpg` es la foto que aparece al compartir el enlace (WhatsApp, Facebook).
- Los `.png` de la raíz son los originales en alta resolución y no se cargan en las páginas.
- Para cambiar una foto, reemplaza el `.webp` correspondiente (lo ideal es un máximo de 1200 px de lado, y 1600 px para la fachada).
- El ícono de la pestaña del navegador está en `img/favicon-32.png`, `img/favicon-192.png` e `img/apple-touch-icon.png`.

## Íconos

Los íconos son SVG insertados en cada página, basados en [Feather Icons](https://feathericons.com) (licencia MIT).
